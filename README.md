# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

## 耗材明细

每个维修事项可记录多条耗材（名称、单价、数量），页面自动计算每条小计和该事项实际费用：

- 未完成事项按预计费用统计；事项标记为已完成后，耗材合计计入「已完成支出」。
- 耗材明细与金额随 localStorage 保存，刷新页面保持不变。

## 浏览器回归测试

使用 Playwright：

```bash
npx playwright install chromium   # 首次运行需安装浏览器
npm test
```

覆盖耗材新增、编辑、移除、小计/实际费用/已完成支出计算、刷新持久化，以及原有新增、删除、状态切换、筛选和本地保存回归。
